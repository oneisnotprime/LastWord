# Starting kits (PLAN.md "Starting kits"): the hand-tuned core that tools/build_kits.py starts from.
# It writes data/kits.json: 100 jobs, 100 buildings and the legendary words.
#
# job <word>: tokens
#   A job is worn like an invisible tool for the whole round, so it acts only through shared
#   properties, with the same tokens as demo_words.txt:
#   p=v      the job's own property, read as any carried tool's is: harvest_sources and
#            harvest_bonus (gathering success, extra letters a hunt), trade_rate (markets ask this
#            times their price), command_limit, authority, recruit_rate
#   p*x p+x  what it does to its holder's body (sight_range, speed_land, strength, armor,
#            integrity, accuracy, stealth, res_*...); produce_<L>*x multiplies every L its
#            holder earns, as an area's yields do (shared place.ts)
#   letters=abc   letters its starting hand leans toward
#   A core job whose word is not in the dictionary yet is skipped (the build lists it); the rest
#   of the hundred are derived by rule from the dictionary's profession words.
#
# building <word>   a starting building: placed at its owner's spawn, theirs, as if spelled there
# skip <word>       never a job or a starting building
#
# legend <word>: unlock=<condition> counter=<word>
#   conditions: minutes:N (round time), letters (pay half its letters), land:N (tiles held),
#   boss (slay a roaming boss), producers:N (things of yours making letters), regions:N (regions
#   explored), hunts:N (wild animals hunted), trades:N (trades made), city (rule a city),
#   kills:N (people killed). The counter must name the legendary in its `counters`.
