# Generator rules (tools/rules.py; README "Generator rules"). Applied by build_demo.py after
# demo_words.txt and generated_words.txt: every word whose meaning matches gains the properties,
# unless it already sets them. Earlier rules win (a word keeps the first value it gets).
#
# Kinds decide whom a rule binds (server): an area (a field, an event with a radius, a thing that
# radiates) binds whoever it reaches, its maker's side spared what hinders; an act passed on a
# person binds them; a verb binds its speller; anything else owned binds its owner.
