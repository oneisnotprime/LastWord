# Last Word: word and property data

Design data only; no game code yet. Everything in `data/` is generated by `tools/`.

| File | Contents |
|---|---|
| `data/lexicon.tsv` | Every word with a game role, one row per word under its most useful role |
| `data/inert.tsv` | Words with no role yet, kept with their WordNet category |
| `data/proper.tsv` | Names of people and places (excluded) |
| `data/overrides.tsv` | Hand rulings on a word's role and archetype; these win over the automatic choice |
| `data/inflections.tsv` | Comparatives and superlatives of common adjectives, with their base word |
| `tools/producers.txt` | Hand-written: the only source of every word's `produce_*` values (PLAN.md "Letter economy") and what each producer needs (`production_needs`) |
| `data/demo.json` | Property values for the 351-word demo dictionary, built from `tools/demo_words.txt` |
| `data/demo_candidates.tsv` | Short, very common words to hand-pick a demo dictionary from |
| `data/properties.json` | The property schema: id, group, type, default, meaning |
| `data/archetypes.json` | Each class and archetype, its word count and the property groups it fills |
| `data/letters.json` | All 26 letters: class, source, share of letters across the lexicon |
| `data/operators.json` | Adjective operations and the seed list of absolute adjectives |
| `data/watchlist.tsv` | Words whose meaning is strong for their spelling cost, ranked by cost within each reason |
| `data/stats.json` | Counts by role, class, archetype and frequency tier |

## Columns in the word lists

`word`, `role` (noun, verb, adjective, adverb), `class`, `archetype`, `zipf` (frequency, 0 to 8;
higher is more common), `tier` (core, common, uncommon, rare, obscure), `synset` (WordNet id of
the meaning used), `other_roles` (roles the word could have had).

## How a word gets its role and class

- Each word has one role. The choice weighs how often the word is used that way against how
  useful the role is in play (objects first, then events, then modifiers, then verbs).
- Nouns take the archetype of their nearest WordNet ancestor on the anchor list in
  `tools/build_lexicon.py`, falling back to the WordNet category. The meaning used is the first
  of the word's three most common senses that has a role.
- Acts and events (war, theft, fire) are the `event` class: words dropped on a target or area
  that make something happen.
- `overrides.tsv` corrects any word by hand. Every demo word is pinned there.

## Property values

`tools/demo_words.txt` is the hand-written source. `p=v` sets the word's own property. `p*x` and
`p+x` change that property on whatever the word modifies: an adjective's noun, a verb's caster,
or the things inside an aura, weather or event. Properties not listed stay at their default.

Comparatives and superlatives reuse the base adjective's operations at a higher degree
(`operators.json`): a multiplier `f` becomes `f ** degree`, an added amount `a` becomes
`a * degree`.

## Areas, places and concepts

Any word's area (an event, a field, weather, or an object with a `field_radius`) can change the
letter economy and the rules where it lies, through shared `place.ts`:

| Property | What it does inside the area |
|---|---|
| `produce_<L>` and `harvest_bonus` operations | multiply every L (or every letter) earned there: gathered, produced, from kills, deeds and trades |
| `growth` | how fast picked ground grows back (0: never) |
| `deposit_factor` | ground deposits multiplied as it begins (0 strips them) |
| `tax_rate` | share of letters others earn there that goes to its maker |
| `lode`, `lode_share`, `lode_stock` | letters gathering there turns up instead, and how many |
| `trade_rate` | markets there ask this times their usual three letters for one |
| `law` | acts nobody it reaches may do there: attack, gather, spell, trade, theft |
| `summons`, `summon_count`, `summon_owned` | creatures that appear as it begins, wild or its maker's |
| `tile_type` + `radius` on an event | the land it lays as it begins (a METEOR's crater) |

Broad concepts of a few hundred words each (TODO.md "Dictionary themes"), each built on a shared
system in `shared/`. The core words of each are hand-written in `tools/demo_words.txt` under
"Dictionary themes"; the rest were generated from them by `generate_words.py`'s prompt.

| Theme | Shared system | What the words do | Counters |
|---|---|---|---|
| Materials and elements (11) | `material.ts` | A material before a noun, or an adjective naming one, remakes the thing: GLASS SWORD is sharp and shatters, IRON DOG armoured, heavy and slow, PAPER CASTLE burns, SILVER blades hurt the unholy. A precious material carried cuts what transmuting to Z costs, and is used up | blows on brittle things, fire on flammable and low-melting ones, lightning on conductors, ACID, RUSTY |

## Generating more words

`tools/generate_words.py` gives property values to more of the lexicon with Claude, through the
Message Batches API. It picks the most common words that are not hand-written (leaving out
grammar words), sends them twelve at a time with the property schema and every line of
`demo_words.txt` as examples, and writes `tools/generated_words.txt` in the same format.

```
python tools/generate_words.py prepare 3000 <wordnet dict dir>   # pick words, write requests
python tools/generate_words.py pilot 2                           # try two requests at full price
python tools/generate_words.py submit                            # send the rest as one batch
python tools/generate_words.py status
python tools/generate_words.py collect                           # write generated_words.txt
python tools/generate_words.py merge                             # or: add .generate/chunks/out_*.txt to it
tools/build_all.sh <wordnet dict dir>
```

`build_demo.py` checks generated lines leniently: a bad token is dropped and a word it cannot
place is skipped, both listed in `data/generated_problems.txt`. Hand-written words always win.
Needs `pip install anthropic` and an `ANTHROPIC_API_KEY`.

## Rebuilding

```
npm i wordnet-db            # WordNet dict files
pip install wordfreq
tools/build_all.sh node_modules/wordnet-db/dict
```
